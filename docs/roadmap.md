# Mann roadmap

## Completed milestone

- React/Vite and MapLibre navigation view
- Fixed vehicle overlay and camera bearing
- Speed, pause/start, restart, HUD, and route progress simulation
- Node backend with validated route endpoint
- OSRM driving integration with full road geometry
- Coordinate route form, custom values, and Belo Horizonte/Ouro Preto/São Paulo presets
- Vite LAN host and `/api` proxy
- Simulation time multiplier for long routes

## Next major phase

Add turn-aware navigation presentation: route step metadata, maneuver cues, road names, and a compact next-turn panel. Keep geocoding, persistence, traffic, and local OSRM datasets out of that phase until the navigation core is stable.
